**Recent work**

- **[GA4 Enhanced Measurement breaks on modern forms](https://angeliquedf.dev/case-studies/ga4-enhanced-measurement-misses-new-leads/)** — A technical comparison between a native Astro form and a React/Mantine form. On the React form, `form_submit` never fired; on the native form, it counted failed validation attempts. Fixes: client and server Zod validation, Post/Redirect/Get to remove PII from the URL, and a custom success event after a 200 OK response.
- **[Google Ads Acquisition Planner](https://angeliquedf.dev/projects/google-ads-acquisition-planner/)** — A budget planning tool that works backward from a revenue goal through paid jobs, quote requests, clicks and budget. Pure TypeScript calculation model, React/Mantine interface, Netlify CI and Git hooks.
